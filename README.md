# Object-Oriented Inventory Management System

Console and logic-based inventory tracking application implementing core OOP principles (encapsulation, collections) developed for UNIMAS academic coursework.

## 📂 Files Included
* **`Main.java`** - Execution controller and interactive menu loop.
* **`InventoryItem.java`** - Core model class representing individual inventory items with encapsulation.
* **`InventoryManager.java`** - Business logic handling collection arrays and stock updates.
